# Banquet-system

## 1. 프로젝트 소개
- 현장에서 수정이 빈번한 운영 시트 및 행사 운영 내용을 현장에서 간편하게 조회 및 수정이 가능한 프로그램 

## 2. 문제 상황
1. 기존에는 BEO(운영 내용 서류), 행사 아젠다, 테이블 배치도 등 여러 운영 파일들을 전자결재 -> 사내 공유폴더 + 사내 행사 일정 관리 프로그램
-> 사무실 초안 검토 후 출력 -> 현장 직원들 복사 라는 번잡하고 긴 시간이 소요되는 흐름을 변경하고 싶었음 수정이 되면 같은 단계들을 반복함
2. 사무실 PC로 프로그램을 확인하지 않는 이상 행사 전체 일정이나 BEO등 운영 내용을 확인할 수 없었음
3. 이로 인해 구두로 변경내용이 전달되면 현장 운영 인차지(담당자)나 다른 현장 직원들에게 전파하는 시간 및 수고가 있고 누락이 빈번하게 발생함

## 3. 사용자 역할
- 판촉자: 행사 등록, 월별 행사 조회, 행사 상세 등록, 수정 및 조회
- 현장 인차지: 행사 등록을 제외한 나머지
- 기타 현장 직원: 조회 업무만 가능

## 4. 핵심 기능
### 1차 구현 기능
1. 행사 일정 등록 및 운영 시트 반영
2. 월별 전체 행사 스케줄 확인
3. 권한이 있는 사용자 수정
4. 수정 시 로그 + 최신본 표시 남기기
5. 행사 운영 시트 및 이미지 파일 조회

### 추후 구현 기능
1. 정산 여부 확인 및 최신본 이외 이전 버전 시트 조회
2. 사용자 별 행사 운영 내용 확인 여부

## 5. 비즈니스 규칙
1. 같은 날짜 및 같은 공간에 행사 2개 이상 등록 불가능
2. 시작 시간이 종료 시간 보다 빨라야 함
3. 행사 등록은 판촉자만, 운영 내용 수정은 판촉자, 현장 인차지만 가능
   ++ 행사 운영 내용만 인차지가 수정 가능(기본내용 x, 식사 및 음주류나 운영 내용만)

## 6. 도메인 구조
- Event: 행사 기본 정보
- BEO: 행사 운영 정보
- EventAttachment: 행사 관련 추가 파일
- Member: 사용자 정보

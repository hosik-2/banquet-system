# Banquet-system

## 1. 프로젝트 소개
- 현장에서 수정이 빈번한 운영 시트와 행사 운영 내용을, 현장에서 간편하게 조회하고 수정할 수 있도록 만든 프로그램입니다.

## 2. 문제 상황
1. 기존에는 BEO(운영 내용 서류), 행사 아젠다, 테이블 배치도 등 여러 운영 파일을  
   전자결재 → 사내 공유폴더 및 사내 행사 일정 관리 프로그램 반영 → 사무실 초안 검토 후 출력 → 현장 직원 복사  
   방식으로 처리해야 했습니다.  
   수정이 발생할 때마다 같은 과정을 반복해야 해서 비효율이 컸습니다.

2. 사무실 PC에서만 프로그램을 확인할 수 있어, 현장에서는 행사 전체 일정이나 BEO 등 운영 내용을 바로 확인하기 어려웠습니다.

3. 변경 사항이 구두로 전달되는 경우가 많아, 현장 운영 인차지(담당자)나 다른 현장 직원에게 전달하는 데 시간과 수고가 들었고, 누락도 자주 발생했습니다.

## 3. 사용자 역할
- 판촉자: 행사 등록, 월별 행사 조회, 행사 상세 조회 및 수정
- 현장 인차지: 행사 등록을 제외한 기능 수행
- 기타 현장 직원: 조회 기능만 가능

## 4. 핵심 기능
### 1차 구현 기능
1. 행사 일정 등록 및 운영 시트 반영
2. 월별 전체 행사 스케줄 조회
3. 권한이 있는 사용자만 수정 가능
4. 수정 시 로그 기록 및 최신본 표시
5. 행사 운영 시트 및 이미지 파일 조회

### 추후 구현 기능
1. 정산 여부 확인
2. 최신본 이외 이전 버전 시트 조회
3. 사용자별 행사 운영 내용 확인 여부 관리

## 5. 비즈니스 규칙
1. 같은 날짜와 같은 공간에 같은 시간이라면 행사를 등록할 수 없습니다.
2. 시작 시간은 종료 시간보다 빨라야 합니다.
3. 행사 등록은 판촉자만 가능하며, 운영 내용 수정은 판촉자와 현장 인차지만 가능합니다.
4. 단, 행사 기본 정보는 수정 범위를 제한하고, 식사/음주류/운영 내용 등 운영 관련 항목은 현장 인차지가 수정할 수 있습니다.

## 6. 도메인 구조
- Event: 행사 기본 정보
  - status: CONFIRMED / CANCELLED / PENDING
- BEO: 행사 운영 정보
- EventAttachment: 행사 관련 추가 파일
- Member: 사용자 정보

## 7. 기술 스택
- Language: Java
- Framework: Spring Boot
- Database: MySQL
- Build Tool: Gradle

## 8. 현재 구현 상태
- 행사 등록 기능 구조 구현 중
- Authentication: 현재 Spring Security 도입 전 단계로
X-Member-Id Header 기반의 임시 인증 방식을 사용한다.
